화면 판서 1.1 사용법

설치 없이 Panseo.exe를 더블클릭하면 바로 실행됩니다. USB에 넣어 다녀도 됩니다.
실행하면 화면 오른쪽에 세로 도구 막대가 뜹니다. 막대 맨 위 점 무늬 부분을 끌어서 옮길 수 있습니다.

[두 가지 상태]
마우스 : 그린 그림은 화면에 남아 있고, 마우스는 아래 PPT나 영상을 그대로 조작합니다.
판서 중 : 마우스로 화면 위에 그립니다. 아래 화면은 클릭되지 않습니다.

막대 맨 위 버튼이나 Ctrl+Shift+D로 두 상태를 오갑니다.
마우스 상태에서 펜이나 도형 버튼을 누르면 자동으로 판서 상태가 됩니다.
판서를 끄면 직전에 쓰던 창(슬라이드쇼 등)으로 포커스가 돌아가서 방향키로 슬라이드를 바로 넘길 수 있습니다.

[글상자] (1.1에서 추가)
도구 막대의 '가' 버튼이나 T 키를 누릅니다.
화면을 끌면 그 너비만큼 상자가 생기고, 그냥 클릭하면 그 자리에 넓은 상자가 생깁니다.
상자에 한글/영어로 타자를 치면 되고, 줄이 길면 상자 너비에서 자동으로 줄이 바뀝니다. Enter는 줄바꿈입니다.
입력을 마치려면 Esc, Ctrl+Enter, 또는 화면 다른 곳을 클릭합니다. 그러면 상자 테두리와 배경이 사라지고 글자만 화면에 남습니다.
입력 중에 막대에서 색이나 굵기(= 글자 크기)를 누르면 바로 바뀝니다.
글상자 도구로 이미 쓴 글을 클릭하면 다시 고칠 수 있습니다. 내용을 다 지우고 마치면 그 글은 없어집니다.
지우개를 글에 갖다 대면 글상자 하나가 통째로 지워집니다.

[단축키 - 어디서나]
Ctrl+Shift+D   판서 켜기/끄기
Ctrl+Shift+X   전체 삭제

[단축키 - 판서 중일 때]
P 펜 / H 형광펜 / E 지우개 / T 글상자
L 직선 / A 화살표 / R 사각형 / O 원
1~6           색 (빨강, 파랑, 초록, 노랑, 검정, 흰색)
[ ]  또는 마우스 휠   굵기 조절 (글상자에서는 글자 크기)
Ctrl+Z / Ctrl+Y   되돌리기 / 다시 실행
Delete        전체 삭제
Esc           판서 끄기 (마우스 상태로)

[알아두면 편한 것]
- 오른쪽 버튼을 누른 채 끌면 어떤 도구를 쓰고 있든 지우개로 지워집니다.
- 지우개는 닿은 선을 한 획 단위로 통째로 지웁니다.
- 직선·화살표는 Shift를 누르고 그리면 수평, 수직, 45도로 맞춰집니다.
- 사각형·원은 Shift를 누르고 그리면 정사각형, 정원이 됩니다.
- 전체 삭제도 Ctrl+Z로 되살릴 수 있습니다.
- 모니터를 여러 대 쓰면 모든 화면에 그릴 수 있습니다.
- 막대 아래쪽 ^ 버튼으로 막대를 접어 두면 판서 버튼만 남습니다.
- 종료는 막대 맨 아래 X 버튼입니다. 그린 내용은 저장되지 않습니다.

[처음 실행할 때]
서명이 없는 프로그램이라 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다.
"추가 정보"를 누른 뒤 "실행"을 누르면 됩니다.
학교 보안 프로그램이 실행을 막으면 정보 담당 선생님께 예외 등록을 요청해야 합니다.
